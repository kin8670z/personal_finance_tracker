갤럭시 결제문자 자동 등록 3가지 방법

복사·붙여넣기 없이 문자를 가계부에 즉시 넣는 방법입니다.

⚡ 방법 1. 갤럭시 [모드 및 루틴] + 클립보드 원터치 버튼 (가장 간편!)

1) 갤럭시 설정 ➔ 모드 및 루틴에서 [언제: 메시지 수신(키워드: 승인)] ➔ [무엇을: 아르곤 가계부 열기]를 등록합니다.

2) 문자가 오면 상단 알림에서 [복사]만 누르고, 열린 가계부에서 초록색 [📋 복사한 결제문자 1초 자동등록] 버튼만 터치하면 끝!

📲 방법 2. 갤럭시 문자 [공유] 목록에 가계부 띄우기

1) GitHub 저장소에 정식 manifest.json과 sw.js 파일이 함께 올라가 있어야 안드로이드가 공유 대상 앱으로 인식합니다.

2) 갤럭시 크롬(Chrome)에서 가계부를 [앱 설치]한 뒤, 문자 메시지를 길게 눌러 [공유] ➔ [아르곤 가계부]를 선택하면 즉시 등록됩니다.

🔗 방법 3. 문자 자동 전달 앱 연동 (100% 무인 자동화 URL)

SMS Forwarder, MacroDroid 같은 자동화 앱에서 아래 URL 형식으로 문자를 전달하도록 설정하면 화면이 열리자마자 무인으로 등록됩니다.

https://내주소.netlify.app/?sms={문자내용}&auto=1
